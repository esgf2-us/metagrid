## Summary

1. Fixed issues with facets and aggregations related to CORDEX-CMIP6 and removed default facets from the frontend U.I code so that facets are now to be configured from the projects.json. This prevents unsupported facets from being included by the defaults and helps avoid 400 errors from the STAC API's.
2. Fixed saved searches not working for logged-in users with dynamically configured STAC projects.
3. Minor bug fixes and dependency updates.
