## Summary

1. Added "Publish Date" filter to the Additional Properties section on the search page for STAC projects, allowing users to filter datasets by their publication/catalog addition date using ISO datetime format.
2. Enhanced saved searches with full backend synchronization - filters, and search metadata now persist across sessions, devices, and browsers.
3. Improved saved search management - "Remove All Searches" button added to tab bar for better space utilization, with proper backend deletion when authenticated.
4. Fixed issues with facets and aggregations related to CORDEX-CMIP6 and removed default facets from the frontend U.I code so that facets are now to be configured from the projects.json. This prevents unsupported facets from being included by the defaults and helps avoid 400 errors from the STAC API's.
5. Fixed saved searches not working for logged-in users with dynamically configured STAC projects.
6. Added support for Citation and ES-DOC tabs in search results for STAC projects.
7. Minor bug fixes and dependency updates.
