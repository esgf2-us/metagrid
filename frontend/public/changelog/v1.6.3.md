## Summary

1. Added subscription feature for saved STAC searches - users can subscribe to searches and track new datasets added since their last check using the `properties.created` filter.
2. Implemented Changes Dialog for subscribed searches with time range options (Since Subscription, Yesterday, Last Week, Last Month, Custom) to view datasets created within specific timeframes.
3. Added "Created Date" filter to the Additional Properties section on the search page for STAC projects, allowing users to filter datasets by their creation/catalog addition date using ISO datetime format.
4. Enhanced saved searches with full backend synchronization - subscription status, created date filters, and all search metadata now persist across sessions, devices, and browsers.
5. Improved saved search management - "Remove All Searches" button added to tab bar for better space utilization, with proper backend deletion when authenticated.
6. Minor bug fixes and dependency updates.
