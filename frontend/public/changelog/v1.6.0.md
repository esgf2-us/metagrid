## Summary

1. Added runtime configuration for customizing available projects without rebuilding the application. Site admins can now add additional projects, create whitelists of allowed projects, or blacklist projects they want to hide.
2. Added CMIP7 and CORDEX-CMIP6 projects to the available project list.
3. Introduced batch loading for STAC search results, significantly improving initial load times by fetching results in 100-item increments while maintaining pagination functionality.
4. Enhanced Download All Results feature to support batch loading, added "Set Preferred Nodes" functionality for data node selection, and implemented automatic result count limits (disabled for searches with 10,000+ results).
5. Improved error handling for failed searches caused by invalid facets, with automatic detection and highlighting of problematic filters and options to revert to the last successful search.
6. Fixed "Only Globus Transferrable" filter to properly clear cached results and trigger new searches when toggled.
7. Performance improvements including cached aggregation results and optimized search results display.
8. Enhanced user interface with improved banner display, better facet loading when some facets are unavailable, and more accurate results count from STAC searches.
9. Other minor updates and bug fixes.
