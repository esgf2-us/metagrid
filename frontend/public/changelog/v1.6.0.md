## Summary

1. Added runtime configuration for customizing available projects without rebuilding the application. Site admins can now add additional projects, create whitelists of allowed projects, or blacklist projects they want to hide.
2. Added CMIP7 and CORDEX-CMIP6 projects to the available project list.
3. Performance improvements including faster STAC searches, cached aggregation results, and optimized search results display.
4. Enhanced user interface with improved banner display, better facet loading when some facets are unavailable, and more accurate results count from STAC searches.
5. Other minor updates and bug fixes.
