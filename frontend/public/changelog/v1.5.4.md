## Summary

1. U.I changes to the facets filter component on the left of the search page:
    - Increased size and consistency of the filter option drop-downs to improve readability.
    - Updated 'Expand' and 'Collapse' feature to uniformly work for all collapsible panels.
    - The 'keyword search' has been relocated from the top navigation bar, to the bottom of the filter options.
    - Filename search was not reliable in certain cases and has been removed until further notice.
2. Made changes to site deployment:
    - Added the option to configure admin support information on the help page.
    - Added the 'none' authentication option for deployments where user sign-in is not supported.
    - Added WGET integrated with Metagrid backend (optional).
    - Added DATABASE_URL configuration option for production deployments, if not configured, a valid default value is used.
    - Updated the config helper script to reflect new changes to configuration options.
    - The postgres container version has been updated from version 11 to 12. Added a deployment function to the manage_metagrid.sh script that will refresh versions if a collation mismatch is encountered.
3. Fixed issue where under certain circumstances, globus transfers were failing when user was logged in.
4. Other minor updates and bugfixes.
