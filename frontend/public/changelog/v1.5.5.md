## Summary

1. Added new search download button for STAC related search results which will bypass the cart and directly allow users to download their entire results via Globus or wget.
2. Added new copy URL button within the files table so that an http file URL can be copied to the clipboard, the existing OPeNDAP button now has an icon.
3. Added version date range and version type filters for STAC searches.
4. Added support for mixed STAC and non-STAC Globus transfers from the data cart.
5. Separated the main page interactive tutorial into smaller more manageable tutorials of the different main page areas.
6. Updates to backend deployment and config options.
7. Other minor updates and bug fixes.
