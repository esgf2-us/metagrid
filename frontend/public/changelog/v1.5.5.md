## Summary

1. Added new search download button for STAC search results which will generate a wget script that contains wget download commands for every file in the STAC search results.
2. Added new copy URL button within the files table so that an http file URL can be copied to clipboard, the existing OPeNDAP button now has an icon.
3. Added version date range and version type filters for STAC searches.
4. Added support for mixed STAC and non-STAC Globus transfers from the data cart.
5. Minor updates and bugfixes.
