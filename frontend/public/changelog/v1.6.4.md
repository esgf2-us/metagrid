## Summary

1. Added support for CMIP7 citation URLs with new configurable `METAGRID_CITATION_ALLOWED_HOSTS` setting.
2. Updated esgpull download command feature to support esgpull v0.10.1 with STAC backend compatibility.
3. Added subscription feature for saved STAC searches - users can subscribe to searches and track new datasets added since their last check using the `properties.created` filter.
4. Implemented Changes Dialog for subscribed searches with time range options (Since Last Checked, Since Subscription, Yesterday, Last Week, Last Month, Custom) to view changes to your search results within specific timeframes.
5. Updated search facet buttons so they can display clickable links if the facet is configured to do so. Configured source_id to have a clickable emd link for CMIP7
6. Updated Mock Service Worker (MSW) from v1.3.5 to v2.15.0 for improved testing infrastructure and maintenance.
7. Fix bug where table shows old cached search results after new search is completed.
8. Minor bug fixes and dependency updates.
