## Summary

1. Added support for CMIP7 citation URLs with new configurable `METAGRID_CITATION_ALLOWED_HOSTS` setting.
2. Added subscription feature for saved STAC searches - users can subscribe to searches and track new datasets added since their last check using the `properties.created` filter.
3. Implemented Changes Dialog for subscribed searches with time range options (Since Last Checked, Since Subscription, Yesterday, Last Week, Last Month, Custom) to view changes to your search results within specific timeframes.
4. Updated Mock Service Worker (MSW) from v1.3.5 to v2.15.0 for improved testing infrastructure and maintenance.
5. Minor bug fixes and dependency updates.
