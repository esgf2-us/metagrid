## Summary

1. Added subscription feature for saved STAC searches - users can subscribe to searches and track new datasets added since their last check using the `properties.created` filter.
2. Implemented Changes Dialog for subscribed searches with time range options (Since Subscription, Yesterday, Last Week, Last Month, Custom) to view datasets created within specific timeframes.
3. Updated Mock Service Worker (MSW) from v1.3.5 to v2.15.0 for improved testing infrastructure and maintenance.
4. Minor bug fixes and dependency updates.
